# Ejecución

- Debe tener instalada la librería `UV` para ejecutar ambientes virtuales de python
- Ejecute el comando:

```bash
$ uv run ./src/load_data.py
```

- Al final de la ejecución verá en consola el resultado del Dataframe procesado

## Estructura

- El archivo `load_data.py` contiene el código de lectura de los datos y transformaciones
- La carpeta `data` contiene el archivo `CSV` donde estan los datos en crudo
